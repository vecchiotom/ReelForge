# `public/` asset guidelines

Files in this directory are served as-is (favicons, manifest icons, and any other static
assets) — Next.js does not run its own image-optimization pipeline over them the way it does
for `next/image` sources referenced elsewhere in the app. Keep them lean:

- **Raster images (PNG/JPEG) committed here should be ≤200KB each**, before any optimization
  Next.js might apply at request time. Run them through an external optimizer (e.g.
  [`squoosh.app`](https://squoosh.app), `pngquant`, `oxipng`, or `sharp`) before committing.
- Favicons and app icons are generated by `scripts/generate-icons.mjs` (`npm run icons`) from a
  single source image — regenerate through that script rather than hand-exporting new PNGs, so
  sizing and compression stay consistent.
- **SVGs should be minified** (e.g. with [SVGO](https://github.com/svg/svgo)) and stripped of
  editor metadata — no Inkscape/Illustrator `<sodipodi:*>`/`<inkscape:*>` namespaces, comments,
  or unused `<defs>`.
- Before committing, a quick sanity check: `find site/public -size +200k` should return nothing.
