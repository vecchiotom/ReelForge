# `public/` asset guidelines

Files in this directory are served as-is under this app's `/app` basePath (e.g.
`public/favicon-192.png` → `/app/favicon-192.png`) — Next.js does not run its own
image-optimization pipeline over them the way it does for `next/image` sources referenced
elsewhere in the app. Keep them lean:

- **Raster images (PNG/JPEG) committed here should be ≤200KB each**, before any optimization
  Next.js might apply at request time. Run them through an external optimizer (e.g.
  [`squoosh.app`](https://squoosh.app), `pngquant`, `oxipng`, or `sharp`) before committing.
- Favicons and PWA icons are generated by `scripts/generate-icons.mjs` (`npm run icons`) from a
  single source image (`assets/logo.svg`) — regenerate through that script rather than
  hand-exporting new PNGs, so sizing and compression stay consistent. See `app/manifest.ts` for
  where the generated icons are referenced.
- `sw.js` is the hand-written service worker registered by
  `components/shell/ServiceWorkerRegistration.tsx` — edit it directly, it isn't generated.
- **SVGs should be minified** (e.g. with [SVGO](https://github.com/svg/svgo)) and stripped of
  editor metadata — no Inkscape/Illustrator `<sodipodi:*>`/`<inkscape:*>` namespaces, comments,
  or unused `<defs>`.
- Before committing, a quick sanity check: `find web/public -size +200k` should return nothing.
